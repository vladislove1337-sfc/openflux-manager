# OpenFlux Cups Manager v2.0

Интерактивный установщик + менеджер выходной ноды **OpenFlux / Cups.online** на Ubuntu 22.04 LTS (Python 3.10+, systemd). Не каскад, не proxy-panel. Для нового сервера **сначала пункт 1 (установить), затем пункт 2 (создать комнаты), потом пункты 3 и 8 (данные для iPhone)**.

## Установка самого меню

Перенесите `openflux-manager-v2.zip` на VPS, например в `/root/`, затем от root:

```bash
mkdir -p /root/openflux-manager-v2
python3 -m zipfile -e /root/openflux-manager-v2.zip /root/openflux-manager-v2
sh /root/openflux-manager-v2/install.sh
openflux-menu
```

Эта операция устанавливает **только меню** в `/usr/local/sbin/openflux-menu`; **не трогает** работающие службы, AES-ключ, комнаты и OpenFlux. Пункт **1** внутри меню уже устанавливает сам OpenFlux.

## Пункты меню

1. **Установить / обновить OpenFlux + systemd.** Если бинарник отсутствует, скачивает версию **v0.17.1** из официального репозитория `OpenFluxTeam/OpenFlux` и сверяет SHA256 с `SHA256SUMS.txt` того же релиза. Если бинарник уже установлен, не заменяет его без прямого подтверждения. Создаёт непривилегированного пользователя `openflux`, каталоги, новый AES-ключ только если его ещё нет, управляющий systemd unit и обёртку запуска. На существующем `openflux-cups.service` предлагает резервную копию и миграцию unit, не перезапуская действующий процесс. Новые комнаты не создаёт, чтобы пользователь выполнил следующий пункт вручную.
2. **Создать новые комнаты Cups.** Требует установленной *управляемой* службы из пункта 1. Делает backup `cups.env`, кратко запускает службу без URL, ждёт новый Base64 от OpenFlux, проверяет его и сохраняет в `cups.env`. Повторно перезапускает ноду с сохранёнными комнатами, чтобы при следующем рестарте не создавать новые. Изменение комнат обрывает VPN, требует обновления профиля iPhone.
3. **Показать комнаты + Base64 для iPhone.** Только по подтверждению выводит строку.
4. **Сохранить новые комнаты из журнала.** Использует только *текущий* запуск systemd (InvocationID), не старый набор из истории.
5. **Перезапустить + синхронизировать.** Если обнаружится пересоздание комнат после ошибок `404`, сохраняет новый Base64 и при необходимости перезапускает управляемую службу для закрепления конфигурации.
6. Состояние ноды.
7. Журнал OpenFlux (маскируется длинный Base64).
8. Показать AES-ключ (по подтверждению). Секрет нигде не генерируется заново при повторном запуске установки.
9. Запуск / остановка / автозагрузка.
10. Диагностика / резервные копии.

## Как настроить OpenFlux на iPhone

- «Новый профиль» → режим «Обычный» → транспорт **Cups.online**.
- В поле комнат вставить **Base64** из пункта 3.
- В поле шифрования вставить **AES-ключ** из пункта 8.
- Кодек быстрый **zstd**.
- Сервер работает в режиме `--role=exit --mode=l4` без открытия входящего VPN-порта.

## Директории и защита

- `/opt/openflux/openflux` — бинарник, `/opt/openflux/secret.txt` — секрет AES; файл ключа остаётся существующим или создаётся новым при первой установке.
- `/etc/openflux/cups.env` — комнаты `CUPS_URL=` (0600, root); `/etc/openflux/backups/` — бэкапы с правами 0600.
- `/usr/local/libexec/openflux-cups-launch` — скрипт обёртки, работающий от `openflux` и передающий `--url` **только при непустом `CUPS_URL`**.
- `/etc/systemd/system/openflux-cups.service` — unit с автозапуском. При первом выполнении пункт 1 *включает автозагрузку, но не запускает ноду*, пункт 2 запускает.

## Ограничения

- Без удалённого доступа из Ubuntu к `github.com` пункт 1 не сможет скачать OpenFlux. Для существующей ноды можно использовать установленный бинарник без загрузки.
- `SHA256SUMS.txt` подтверждает совпадение с файлом из того же GitHub-релиза, **не является независимой цифровой подписью разработчика**.
- Для переустановки старой, неуправляемой службы потребуется подтвердить перевод на новый unit; при этом старый unit сохраняется в backups.
- Сервис Cups.online может удалить комнаты. Меню не может гарантировать пожизненные комнаты или самостоятельно записать их в iOS-приложение.
- При перезапуске VPN временно прерывается. Одна лишь надпись `active`/`8 из 8` не гарантирует прохождения трафика — проверяйте на iPhone.
- Меню хранит данные локально и не публикует их в интернет, не предоставляет веб-интерфейса и не открывает порты.
- Удаление `/usr/local/sbin/openflux-menu` удалит меню, но не OpenFlux, службу или конфигурацию.
